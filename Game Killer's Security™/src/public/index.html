Getting Started

Welcome to Game Killers Security Bot! Follow these steps to get started:

Step 1: Invite the bot using the button on the homepage Step 2: Run /gk help to see all available commands Step 3: Configure your security settings in dashboard Step 4: Set up automated rules and moderation Step 5: Monitor threats in real-time from dashboard

Command Reference

/gk help → Show all available commands /gk stats → Display server security statistics /gk report → Report an issue to moderators /gk info → Show bot version and info /gk setup → Configure security settings /gk scan → Run manual security scan /gk ban user → Ban a user from server /gk kick user → Remove user from server /gk logs → View security logs /gk settings → Adjust bot settings

Roblox Plugin Setup

The Roblox plugin provides advanced security monitoring for your games:

Step 1: Download plugin from Roblox Creator Store Step 2: Insert into ServerScriptService Step 3: Connect with your bot API key from dashboard Step 4: Configure detection sensitivity levels Step 5: Monitor exploits in real-time Step 6: Set automatic ban thresholds
